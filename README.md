# Cooked-Hollow
The spells needed for a Grim Hollow + Crooked Moon game.

**Step 1**: Grab the Raw URLOnce the page, look at the top right of the code block and find the "Raw" button.Right-click the "Raw" button and select "Copy link address" (or click it and copy the URL from your browser's address bar). 
**Step 2**: Link it to Avrae in Discord. Go to your Discord server where the Avrae bot is installed.In your bot channel, type the following command, replacing <YOUR_RAW_URL> with the link you just copied:
!tome subscribe <YOUR_RAW_URL>
Avrae will reply to confirm it has successfully read the file and registered your new custom tome.
**Step 3**: Test it out! Type !spell blood bolt+ or !spell dissolution+ in Discord. If the bot responds with the spell details and the correct description, your tome is successfully live!
